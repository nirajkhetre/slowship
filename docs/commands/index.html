Commands and options

Everything slowship understands, on one page.

#Commands

CommandWhat it does
slowship [dir]Read dir (here by default), show the verdict, then offer the review.
slowship reviewReview the last watch again, full screen in the terminal.
slowship uiOpen the morning report in your browser.
slowship schedule [dir]Keep watch every night. See The nightly watch.
slowship discordConnect a Discord channel for the morning ping.
slowship telegramConnect a Telegram chat for the morning ping.
slowship notifyShow, test or stop the morning ping.
slowship connectPrint how to connect your coding agent, and install its skill.
slowship mcpThe MCP server your agent talks to. Your agent starts it; you don’t need to.
slowship helpThe mark and the list of commands.

#Watch options

OptionWhat it does
--app <folder>Also check your own build before it ships.
--no-modelRules only, no local model.
--packages-onlyRead only the project’s packages.
--agents-onlyRead only agent skills and MCP servers.
--offlineDon’t download npx MCP servers to read them.
--json <file>Write everything found as JSON.
--approve <name|notable|review>Clear one item, or everything at that level and below. See Clearing things.
--notifySend the morning ping after this watch too.
--plainPlain text: no colour, no screens. Automatic when piped.
--no-motionDraw, but don’t animate.

#Other options

CommandOptions
slowship ui--port 7798 to choose the port, --no-open to start without opening the browser.
slowship schedule--at 03:00 for the time, any watch option to keep for the nightly run, --status to see what’s set, --off to stop it.
slowship notifytest sends one now. off [discord|telegram|all] disconnects. when needs|always chooses when it sends. manual on|off also sends after watches you start.

#Environment variables

VariableWhat it does
SLOWSHIP_MODELThe Ollama model to use. Default gemma4:e2b.
SLOWSHIP_HOMEWhere slowship keeps its memory. Default ~/.slowship.
SLOWSHIP_REAWhere REA’s scripts/rea.mjs is, if it isn’t installed globally.
SLOWSHIP_PORTThe report’s port, instead of --port.
SLOWSHIP_NO_MOTIONThe same as --no-motion, everywhere.
NO_COLORPlain text, like --plain.

#Exit codes

2 when the verdict is held, so it can gate CI; 0 otherwise. The nightly task always exits cleanly; the verdict waits in the report.

#Files

FileHolds
~/.slowship/state.jsonThe memory of what was read, by fingerprint, and your clears.
~/.slowship/notify.jsonThe morning ping’s webhook or token, readable only by you.
