Using it

The terminal review

You don’t have to leave the terminal. After a watch, press ↵ on the verdict card, or run slowship review any time, and the whole review opens full screen.

#Open it

slowship review

It reviews the last watch again, from memory, without reading anything twice.

#What’s on the screen

Four tabs run along the top:

  • Review: what needs you, held things first. Each card has a rail in its colour.
  • Aboard: everything that was read.
  • Keys: who can spend your money, by outside account.
  • Blind spots: where it couldn’t look.

Beside the list is the inspector: what the item says, what its code does with the real lines around each finding (the flagged one lit), the model’s note, the IPC map, what compiled files are built from, and the keys it holds.

#Keys

KeyWhat it does
↑ ↓Move through the list
← →Switch tabs
↵Open the selected item in the inspector
cClear it. It slides away.
uUndo the last clear
/Search, or type a command like /discord
fFilter by kind
oOpen the morning report in the browser
rWatch again
?Show every key
EscStep back. It never quits.
qQuit. The terminal is always put back as it was.

The mouse works too: click to pick, use the wheel to scroll. When the last thing is cleared, the ship sails.

#Commands inside the review

Press / and type a command:

  • /discord and /telegram connect a morning ping without leaving the review.
  • Anything else you type searches what’s aboard.

#Small and odd terminals

Below 110 columns, the inspector opens over the list instead of beside it. Below 60 by 16, it asks for more room rather than drawing something broken.

It uses true colour where the terminal has it, and 256 or 16 colours where it doesn’t.

#Plain text, no motion

When the output is piped, in CI, overnight, with NO_COLOR set, or with --plain, slowship prints plain text instead of drawing, and the exit code is the same. --no-motion (or SLOWSHIP_NO_MOTION) keeps the drawing but stops all animation.
