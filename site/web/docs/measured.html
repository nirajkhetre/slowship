Every number slowship quotes was measured, on real code, on one laptop. Here they all are, with what they don’t say.

One real project

One project folder: the 174 dependencies of REA’s own npm package, plus 77 installed skills, 1 MCP server and a deliberately risky test build. A laptop with a 6 GB GPU, using gemma4:e2b.

Against known malware

Measured on 200 agent skills from MalSkillBench: 100 malicious and 100 benign, a fixed and reproducible subset. Each rate has a range it is 95% likely to sit in, because 100 samples can’t pin it to the decimal.

Rules onlyRules and gemma4:e2b
Held12 of 100 malicious skills (7–20%), 2 of 100 benign13 malicious (8–21%), 3 benign
Held or worth a glance53 malicious (43–62%), 17 benign (11–26%)33–36 malicious, 8–9 benign, over two runs
Benign npm packages flagged (REA’s 174 dependencies)0 held, 18 worth a glance0 held, 3 worth a glance

Put plainly

  • A hold is usually right: 12 of 14 (between 60 and 96%).
  • It catches about one malicious skill in eight as a hold. Most misses are attacks written as plain English in SKILL.md, or code inside a markdown block, which slowship doesn’t read as code yet.
  • The model cuts false alarms by half or more, and it also lets more attacks through, because those attacks come with a description written to make them look expected.
  • Malicious npm packages haven’t been measured yet.
