Ship safe, slowly. Does everything aboard do what it says?                 

                                                                                                
Watch                                                                                           
  slowship [dir]                      read dir (here by default), then review it                
  slowship review                     review the last watch again                               
  slowship ui                         the morning report, in your browser                       
  slowship schedule [dir] --at 03:00  keep watch every night (--off, --status)                  
                                                                                                
Options                                                                                         
  --app <build/>                      also check your own build before it ships                 
  --no-model                          rules only, no local model                                
  --packages-only, --agents-only      read only one side                                        
  --offline                           don't fetch npx MCP packages to read them                 
  --json <file>                       write everything found as JSON                            
  --approve <name|notable|review>     mark results as seen                                      
  --plain                             plain text: no colour, no screens (also when piped)       
  --no-motion                         no animation                                              
                                                                                                
Your coding agent (optional)                                                                    
  slowship connect                    let it watch, and check before it installs; only you clear
                                                                                                
Morning ping (optional)                                                                         
  slowship discord                    send the verdict to a Discord channel after each nightly w
  slowship telegram                   or to a Telegram chat, through a bot you make             
  slowship notify [test|off]          what's connected; send a test; disconnect                 
                                                                                                
In the review                                                                                   
  ↑↓ move   ←→ tabs   ↵ open   c clear   u undo   / search   o browser   ? keys   q quit        
                                                                                                
  Reads code, never runs it. Exit code 2 when something is held, so it can gate CI.
